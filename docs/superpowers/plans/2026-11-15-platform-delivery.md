# 数据治理中台分阶段实施计划

**目标：** 在单节点部署中交付已确认设计，提供统一界面、数据库处理与运维、数据权限、服务和报表。

**架构：** Java 21 / Spring Boot 模块化服务使用 Apache Camel 作为数据集成路由层，元数据库持久化平台配置及实例；前端使用 Vue 3 和 Element Plus（Element UI 的 Vue 3 版本）。工作流管理与数据权限由平台实现。版本和具体依赖需在各阶段锁定并验证。

**交付顺序及验收：**

1. 基础工程：构建后端、前端、持久化及配置；提供可启动的开发环境和自动化测试。
2. 身份与权限：用户、部门、角色、功能授权、审计；验证服务端拒绝未授权请求。
3. 数据资产：连接凭据加密、连接测试、数据库元数据和数据集登记；分别验证三类数据库。
4. 执行与任务：Camel 数据库同步、SQL 执行、字段映射、追加、更新插入和安全的全量替换；验证数据库差异及失败行为。
5. 调度运维：持久化 DAG、版本、实例、节点日志、依赖调度、定时、重试、补跑及中断恢复；验证并发和故障。
6. 持续同步：轮询、稳定排序游标、写入与游标故障恢复、启停和监控；验证重放与幂等边界。
7. 数据权限：部门及下级行范围、字段权限和脱敏；在预览、报表和服务后端强制执行，测试越权。
8. 服务：受控查询发布、审批、调用方凭据、授权、限流和统计；验证调用方隔离。
9. 报表：数据集字段选择、过滤、聚合、表格、图表和看板；验证权限与查询资源限制。
10. 交付：部署说明、备份恢复、数据库兼容性、端到端和安全验证；明确未覆盖的环境及限制。

各阶段先编写能验证外部行为的测试，确认失败后实现并运行相关测试；依赖真实数据库的行为通过集成测试验证，不能仅凭内存数据库声称兼容。实施期间按具体子系统细化可执行计划。
