# 数据治理平台子系统实施计划

**目标：** 完成已确认设计中的单节点数据治理平台，以真实持久化、服务端授权和可验证的任务执行组成统一产品。

**架构与技术栈：** Vue 3、Element Plus、Spring Boot 3、Java 21、Camel；平台使用 PostgreSQL 保存元数据，以版本化数据库迁移管理模式。集成测试可用 H2 验证平台基本行为，但不能代替 MySQL、PostgreSQL、Oracle 的兼容性测试。凭据主密钥由部署环境提供，不存入元数据库。

**执行规则：** 每个子系统先增加行为测试并观察失败，再实现并运行对应测试；完成后进行规格和安全审查。每一项记录实现状态、验证命令和未覆盖环境。不可因缺少外部数据库而跳过独立模块，也不可将内存模型视为持久化实现。当前目录不是 Git 仓库，不执行提交或 worktree 操作。

| 4 | 数据访问与权限 | 2、3 | 单数据库受控查询、部门与子部门行过滤、角色字段可见和脱敏；预览、报表、服务共用且后端强制，越权测试通过 |

| 8 | 可视化处理界面 | 3、5、6、7 | 拖拽节点和连线、节点参数表单、保存版本、运行及日志；键盘和窄屏可用，后端校验错误可见 |

| 10 | 自助分析和报表 | 2、4 | 授权数据集的字段选择、过滤、分组、聚合、图表和看板；应用行列规则与查询上限 |

## 实施步骤

### 1. 应用基础与元数据

文件：`backend/pom.xml`、`backend/src/main/resources/application.yml`、`backend/src/main/resources/db/migration/`、`backend/src/test/java/com/example/governance/`、`README.md`。

1. 增加 Spring JDBC、Flyway、PostgreSQL 驱动和测试用 H2，固定兼容版本；保留现有 Web 测试。
2. 编写迁移集成测试：启动独立数据库、执行迁移、写入记录、关闭并重开连接、核对记录；测试缺失迁移时失败。
3. 引入版本化迁移和数据库配置；生产数据库 URL、用户及密码从环境注入。测试数据库单独配置，禁止使用硬编码生产凭据。
4. 运行 `mvn -f backend/pom.xml test`；检查迁移重复启动和失败处理，并记录实际使用的数据库。

### 2. 组织、身份与审计

文件：`backend/src/main/java/com/example/governance/security/`、`backend/src/main/resources/db/migration/`、`backend/src/test/java/com/example/governance/security/`、`frontend/src/`。

1. 为部门、用户、角色、用户角色和角色功能权限建表；部门外键约束与环检测必须同时存在。审计事件包含操作者、时间、动作、对象和结果，不记录密码或凭据。
2. 先测试登录成功、密码错误、禁用用户、未登录和无权限访问；使用成熟密码哈希与服务端会话，提供安全配置的初始化管理员流程。
3. 将现有 `AccessPolicy` 接入请求身份与持久化数据；默认拒绝，保护每个管理接口，并测试用户被禁用后会话不可继续使用。
4. 完成组织与角色管理页面，测试授权变更、越权请求与审计记录。任务运行身份是独立服务身份，其全量读取能力不赋予普通用户。

### 3. 数据源与资产

文件：`backend/src/main/java/com/example/governance/assets/`、对应迁移、测试及 `frontend/src/`。

1. 数据源表保存类型、地址、用户名与 AES-GCM 密文；主密钥通过环境注入，启动校验长度与可用性。禁止在日志、API 或错误中暴露凭据。
2. 增加创建、修改、列表、删除及连接测试接口；所有接口要求数据源管理权限。建立测试验证密文持久化、错误密钥失败及响应不含密码。
3. 使用 JDBC 元数据采集 schema、表、列；按数据源登记数据集与字段。测试用户无权读取其他未授权资产。
4. 对 MySQL、PostgreSQL、Oracle 使用真实实例分别执行连接、元数据、错误认证及类型映射测试；不可用的环境记录为未验证。

### 4. 数据访问与权限

文件：`backend/src/main/java/com/example/governance/security/`、`backend/src/main/java/com/example/governance/query/`、对应迁移及测试。

1. 将数据集行规则绑定可信部门字段和用户部门范围，字段规则按角色定义查看、脱敏或禁止；规则缺失默认拒绝。
2. 构建单数据库受控查询：字段名从已登记元数据白名单生成，筛选值参数化；最大行数、超时和并发可配置。
3. 统一预览、报表、服务查询入口，不接受调用方自行指定的权限范围；测试不同部门、子部门、角色、字段及外部调用方绕过尝试。
4. 管理员自由 SQL 走独立授权审批和访问范围配置；未能可靠应用行列权限时拒绝发布。

### 5. Camel 执行

文件：`backend/src/main/java/com/example/governance/execution/`、`backend/src/main/java/com/example/governance/integration/`、对应测试。

1. 定义任务执行接口：输入固定任务版本、实例 ID、业务日期；结果包含状态、数量和错误，不暴露凭据。
2. 使用 Camel 路由调用 JDBC 读取、转换与写入；SQL 节点使用选定连接和受控参数。测试目标失败时返回失败，避免被 Camel 错误处理吞掉。
3. 实现分批追加和按唯一键更新插入；在三数据库分别验证 SQL 方言、事务边界、重复提交和部分失败。
4. 全量替换先准备完整结果，按照数据库能力实施可恢复切换；不能满足约定时拒绝执行并显示限制。日期补跑不可清空全表。

### 6. 批处理任务和工作流

文件：`backend/src/main/java/com/example/governance/workflow/`、对应迁移、测试及 `frontend/src/`。

1. 持久化任务、不可变任务版本、工作流定义、DAG、实例、任务尝试与日志；事务中校验引用和环。
2. 实现单节点调度：在事务内领取待执行任务，确保每次尝试只被启动一次；并行分支仅在所有前置成功后启动。测试并发领取和失败分支。
3. 增加手动/定时触发、超时、有限重试和按业务日期补跑。创建实例时冻结版本，补跑每日期单独实例；日志关联实例和尝试。
4. 启动时将未结束实例标为中断，显式恢复并遵守任务重跑策略；测试进程终止、重启和重试幂等。

### 7. 持续增量同步

文件：`backend/src/main/java/com/example/governance/realtime/`、对应迁移和测试。

1. 建立链路定义、状态、游标、失败和处理量存储；数据库读取按增量字段与唯一键稳定排序。
2. 目标批次成功后持久化游标；失败不推进。写入成功而游标提交失败时允许重放，更新插入需要稳定唯一键。
3. 实现启停、周期、超时及健康状态；测试并发防重、重复时间戳、空批次、目标失败和重启恢复。

### 8. 处理界面

文件：`frontend/src/`、`frontend/tests/`。

1. 在画布上拖动任务节点、连线和删除，保存前调用后端 DAG 校验；支持表单配置数据源、SQL、映射和写入策略。
2. 实现任务/工作流列表、版本保存、触发、实例状态和日志；持续同步独立显示启动/停止、游标和错误。
3. 增加组件和端到端测试，验证无权限控制、过期响应、保存后重载和键盘访问。明确区分真实状态与未接入功能。

### 9. 数据服务

文件：`backend/src/main/java/com/example/governance/serviceapi/`、对应迁移及测试、`frontend/src/`。

1. 实现服务定义、版本、审批记录和发布状态；只能发布经授权的数据集查询或审核的管理员 SQL。
2. 实现调用方凭据、授权范围、限流和调用统计；凭据仅在创建时展示一次，安全存储并支持撤销。
3. 服务请求通过统一数据权限查询，测试跨调用方、篡改部门、字段越权、限流和撤销。

### 10. 自助分析与报表

文件：`backend/src/main/java/com/example/governance/report/`、对应迁移及测试、`frontend/src/`。

1. 实现授权数据集的字段、过滤、分组、聚合和排序查询，执行超时与结果上限。
2. 存储表格、柱状图、折线图配置和看板；重载后权限仍由当前身份动态评估。
3. 测试不可见字段、脱敏字段、部门边界、聚合和超限查询，前端覆盖配置、保存和权限错误。

### 11. 部署、备份与验收

文件：`README.md`、`docs/`、部署配置和端到端测试。

1. 编写单节点部署、环境变量、密钥轮换、反向代理、数据库备份和恢复步骤，禁止把开发配置用于生产。
2. 执行后端测试、前端测试和构建；以真实 MySQL、PostgreSQL、Oracle 运行兼容矩阵，包括连接、同步和权限查询。
3. 在全新环境完成用户创建、数据源登记、同步、工作流、服务发布和报表的端到端流程；记录数据库版本和未验证项目。

## 当前状态与环境缺口（2026-11-16）

已接入持久化组织权限、数据源与资产、受控数据查询、Camel 数据库处理、工作流版本和运行记录、定时与补跑、增量轮询、数据服务和基础报表。工作流画布支持拖动节点，支持拖动连线和通过表单建立依赖；节点位置随版本持久化。独立分支有限并发，汇合节点等待前置成功。

尚未完成全量覆盖、可配置超时和取消及部分管理能力；现有实现和测试不能代表全部验收通过。当前主机有 MySQL 8.0.33，可使用临时实例验证；PostgreSQL 和 Oracle 测试实例尚未确认。三类业务数据库的完整兼容性、端到端部署及故障恢复仍待验证。详细状态见 `docs/verification/database-matrix.md`。

已补充工作流运行历史，支持按状态和业务日期筛选及分页，并可从页面打开实例详情。已新增组织管理权限保护的审计记录查询页面，支持按操作类型筛选及分页。这两类查询已在 H2 接口测试和临时 MySQL 8.0.33 实例上验证；执行日志、失败审计覆盖和其他未完成项仍需继续实现。

### 查询与管理能力进展（2026-11-16）

数据预览、分析、报表和数据服务共用可配置的查询并发、JDBC 语句超时及结果行数限制。数据源删除增加历史任务引用检查和事务锁定；在 MySQL 8.0.33 的旧快照场景中，锁定读可以发现新提交的引用。报表和看板增加更新、删除、所有者校验与引用冲突处理；报表查询配置的完整编辑界面仍未完成。独立任务领取发生瞬时数据库错误时，会尝试将等待中的实例标记为中断。

仍待实现全量覆盖、任务级超时与取消、报表查询配置界面等。数据源删除目前扫描并锁定全部历史任务版本，数据量大时可能造成锁争用，需要进一步优化；PostgreSQL 和 Oracle 的业务数据库兼容性尚未验证。

### 本轮进展（2026-11-16）

完成数据集登记信息删除（引用时拒绝）、角色数据策略查看与撤销、报表查询配置编辑。策略解析改为一致性事务快照，防止并发修改时混合部门字段和字段授权；已开始查询可能在授权撤销后完成。旧角色策略使用部门字段时，不能通过修改其他角色来更换字段。H2 并发和单连接池测试通过，并在 MySQL 8.0.33 测试了并发策略修改快照。完整的固定口径功能统计见 `progress-checklist.md`，外部数据库和端到端验收仍单独追踪。

### 本轮进展（2026-11-16）

独立任务增加失败/中断后的手动重试和尝试记录，固定原版本及业务日期；V22 对历史实例回填尝试记录。工作流节点与独立批处理任务共享可配置并发限制；持续增量同步不纳入该限制。自助分析界面支持多条件及文本、数字、布尔筛选。全量覆盖仍未实现，安全实施约束见 `full-replacement-safety.md`。独立任务目前不自动执行工作流的重试策略。

### 本轮追加进展（2026-11-16）

任务参数界面支持按顺序配置文本、数字、布尔、空值和业务日期；MySQL 已验证这些参数按顺序绑定。分析及报表的数字输入加入精度保护。持续同步在停止或出错时支持调整间隔和批次，映射变更仍须新建任务。数据集支持保守重新采集：只追加新字段且不授予权限，已有字段名称、类型名或可空性变更及删除会被拒绝，但长度和精度变化目前不检查；持源锁跨元数据读取，慢连接可能阻塞源配置修改。启动恢复提前到 WebServer 监听前，并有真实 TCP 时序测试。详细功能计数见 `progress-checklist.md`。

### 本轮数据集与持续同步补充（2026-11-16）

持续同步在 STOPPED/ERROR 时支持仅修改间隔与批次，其他映射及游标变更仍需新建任务。数据集重新采集仅新增字段，不自动授予字段权限，使用锁定读处理 MySQL 旧快照并拒绝已有字段名称、类型名或可空性变化；长度及精度变化当前不检测。JDBC 元数据的 schema 模式使用字面匹配并核对返回对象，避免跨 schema 同名表混合。SQL 参数输入和分析/报表数值筛选均在前端检查可安全表达的数字精度。
