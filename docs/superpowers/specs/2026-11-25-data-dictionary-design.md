# 数据字典设计

## 目标与范围

在“数据资产”下新增“数据字典”，参考 `D:\sparta-project\sparta-damp` 的数据字典，提供目录、字典字段管理与 Excel 导入。界面沿用本项目的导航、列表工具栏、目录树与分页规范。字典是对数据字段的标准定义；本期不自动修改数据源、数据集或业务表。

## 页面和交互

- 左侧为多级字典目录树，提供新增、重命名和删除目录操作。选择目录后，右侧显示该目录及其后代目录的字典；选择根节点时显示全部字典。
- 右侧工具栏左侧是按字典标识、名称、含义匹配的输入框和“查询”按钮，右侧依次提供“新增”“导入”和刷新；回车执行查询。查询时重置到第一页。
- 列表展示序号、字典标识、字典名、字典含义、类型、长度和操作，提供查看、编辑、删除。支持分页，分页位于全高列表面板底部。
- 新增和编辑表单维护所属目录、字典标识、字典名、字典含义、类型、长度、精度和描述。标识创建后保持不可修改；查看展示完整信息。删除前确认。
- 目录树与列表面板在桌面端撑满内容工作区；窄屏时目录在上、列表在下，目录区域高度受限并可滚动。目录操作通过节点操作菜单提供。

## 数据与规则

持久化使用目录表与字典表：目录包含 ID、父目录 ID、名称、排序；字典包含 ID、目录 ID、标识、名称、含义、类型、长度、精度、描述和创建、更新时间。目录使用外键约束；同一父目录下名称唯一。字典标识全局唯一，由数据库唯一约束保证，包括并发新增和导入。

字典标识、名称、含义、类型和目录为必填；标识仅允许英文字母、数字和下划线，首字符为字母或下划线。支持 varchar、char、integer、bigint、decimal、double、date、datetime、boolean 类型；长度为正整数，decimal 和 double 可填写非负精度，且精度不得超过长度。其他类型的精度为空。标识最多 100 字符，名称和含义最多各 200 字符，描述最多 1000 字符。文本去除首尾空格后校验。

目录支持添加子目录和重命名；目录存在子目录或字典时禁止删除并提示先处理下级内容。字典可修改所属目录。目录与字典操作由数据库事务和约束保护，避免并发删除导致悬空引用。

## Excel 导入

导入弹窗提供 `.xlsx` 模板下载和文件选择；模板表头依次为“目录路径、字典标识、字典名、字典含义、类型、长度、精度、描述”，目录路径使用 `/` 分隔，且必须匹配已有目录，不自动创建目录。仅支持 `.xlsx`，文件不超过 5 MB，数据不超过 5000 行，弹窗中说明这些限制。

每行使用与表单相同的校验规则。按文件顺序处理：数据库或本文件中已成功导入的标识重复时跳过该行；其他有效行继续导入。每个有效行独立提交，单行失败不回滚其他成功行；数据库唯一约束冲突按重复处理。结果展示成功数、失败数及失败行号和原因。格式错误、空文件、表头不匹配或超过限制时拒绝整个文件并说明原因。文件仅用于解析，不作为永久附件保存。

## 权限、菜单和审计

在数据资产目录下增加菜单项，新增代码级权限模块，分别控制查看、新增、修改、删除、导入；目录操作复用对应权限，模板下载要求查看权限。后端接口逐项鉴权，前端按权限展示操作；默认超级管理员拥有全部新权限，现有其他角色不自动获得新权限。数据库迁移兼容项目现有 MySQL 和测试数据库迁移路径。

目录新增、修改、删除，字典新增、修改、删除及导入写入审计记录，并在 `AuditCatalog` 中增加操作与对象类型中文名称，使审计列表、筛选、详情和导出都显示中文。导入记录保存成功与失败数量，不记录 Excel 内容或敏感字段值；失败请求按现有审计机制记录结果。

## 架构与数据流

前端独立数据字典页面负责目录树、查询条件、表单和导入结果展示，复用项目权限判断和通用布局。后端按目录管理、字典管理和导入解析分工，使用现有 JDBC、认证、权限和审计机制。列表查询根据目录范围及查询词返回分页结果和总数；导入逐行调用共享校验与持久化逻辑，确保与表单规则一致。

## 验证

- 验证目录层级、同级重名、非空目录删除限制及目录筛选范围。
- 验证字典字段、标识唯一性、类型长度精度校验、分页和新增修改删除。
- 验证 Excel 模板、文件格式与限制、数据库内和文件内重复、部分成功、行号与错误提示，以及并发重复写入。
- 验证无权限接口拒绝与按钮隐藏、超级管理员权限、菜单可见性；确认审计列表、筛选、详情和导出的中文操作及导入数量。
- 以实际项目页面检查桌面和窄屏的目录树、查询工具栏、表格和分页。
