# 单节点数据治理中台设计

## 目标与范围

平台整体部署给单个客户企业使用，提供统一界面，涵盖数据资产、数据处理、数据服务、数据报表和系统管理。首期支持 MySQL、PostgreSQL、Oracle 作为源库和目标库；支持批处理及数据库增量轮询形成的持续同步。Kafka、Flink 留作后续扩展。跨库关联先同步至同一数据库，再执行 SQL。

单节点不具备节点高可用；进程或主机故障会中断任务。平台元数据和执行记录需持久化并纳入备份恢复。

## 架构

采用 Vue 3 + Element Plus 统一前端和 Spring Boot 模块化平台后端，首期不拆分微服务。后端包含组织权限与审计、数据源与资产、工作流与调度、数据服务、自助分析与报表、统一执行入口和 Camel 路由层。平台元数据库保存配置、权限、任务版本、实例、游标和审计记录；业务数据保留在配置的业务数据库中。

统一执行入口负责接收任务配置和运行参数、启动处理过程、反馈状态及停止请求。Camel 是首期统一集成与路由层，负责数据库读写、字段映射、过滤和调用数据库 SQL；SQL 在所选数据库内执行。后续 Kafka 通过接入组件扩展；Flink 可按作业管理需要接入适配器，具体方式后续确定。

工作流表达任务间依赖，Camel 路由表达任务内部处理过程。平台负责调度、持久化和运维，不假定 Camel 自动提供完整工作流管理。

## 数据资产

管理数据库连接、连接测试、元数据采集、表和字段、数据集及授权。连接凭据加密保存，密钥与数据分开管理。数据集归属于单个数据库连接，可供授权用户预览、分析或发布服务。

## 数据处理

### 任务与画布

任务是可独立配置和运行的处理单元。界面通过画布连接节点，选中节点后使用表单配置参数。首期任务包括：

- 数据库同步：选择源和目标、全量或增量读取、字段映射、过滤和写入策略。
- SQL 加工：在选定数据库执行 SQL，支持运行参数和业务日期。
- 实时同步：定期轮询数据库增量数据，持续写入目标并记录游标。

目标写入支持追加、按有效唯一键更新插入、全量覆盖。追加重试可能产生重复。全量覆盖先准备完整结果，再按数据库和表支持的方式替换；不支持原子切换时明确提示其可见性和恢复限制。补跑指定日期不默认清空整表。

### 批处理工作流

工作流由批处理任务和有向无环依赖组成，支持顺序和并行分支；多个前置节点默认全部成功后才启动。支持手动和定时触发、超时、有限重试、查看节点日志、从失败任务恢复和按业务日期补跑。补跑为每个业务日期创建独立实例，任务的数据范围须显式使用该日期。

每次执行生成工作流实例和任务实例，记录业务日期、触发方式、状态、时间、尝试次数、错误及日志。启动时固定任务定义版本；运行中的配置修改不影响该实例。进程重启后将未完成实例标记为中断，由有权限人员按任务重跑策略恢复，不默认全部重跑。

### 持续同步

实时同步任务独立于等待完成的批处理工作流管理，展示启动、停止、健康状态、最近成功时间、游标、处理量和错误。轮询依赖适当的递增字段，支持更新时间加唯一 ID 等稳定排序；不能自动发现无记录的物理删除。目标写入成功后推进持久化游标，重启后从保存的游标恢复。写入成功但保存游标失败可能导致重复，整体按至少一次处理设计；更新插入和稳定唯一键可降低重复影响，不承诺跨库端到端恰好一次。

## 组织与权限

平台为单企业部署，不实现多企业租户隔离。维护部门、用户和角色，通过角色控制菜单及数据源、资产、任务、工作流、服务和报表的操作权限，并审计关键操作。

数据集配置部门字段和本部门或本部门及下级部门的数据范围；字段配置查看权限和脱敏规则。资产预览、自助分析和数据服务由后端统一应用授权，不能只在界面隐藏。处理任务使用独立运行身份，默认可以访问全量数据；任务创建、修改和执行权限单独授予并审计。处理结果登记为数据集后按该数据集的权限访问。

外部系统作为独立调用方，拥有独立凭据、获授权接口和部门数据范围；可关联部门或角色进行管理。服务端根据调用方授权确定范围，不信任调用方自行传入的部门参数。

## 数据服务和报表

数据服务支持基于授权数据集或受控 SQL 配置查询 API、审批发布、调用方管理、鉴权、限流和调用统计。优先通过授权数据集和受控配置生成查询；自由 SQL 仅供管理员使用，必须明确配置访问范围并经过审核，不能假定任意 SQL 可自动安全施加数据权限。

自助分析基于授权数据集，支持字段选择、筛选、分组和聚合，保存为表格、图表或看板。查询在数据集所属的单个数据库中执行，应用行级和字段级规则。平台应限制查询资源与并发，具体阈值在实施时结合环境确定。

## 故障与验证

配置任务重试次数、间隔、超时和并发上限；记录失败原因。区分 Camel 消息级重投递与平台任务级重跑，并确保失败不会被误报为成功。持续链路记录连续失败并支持恢复。

验证覆盖：三类数据库连接及读写、字段映射与 SQL、各写入策略和增量游标；工作流依赖、并发、重试、业务日期补跑和进程中断恢复；部门行级与字段权限、外部调用方授权；服务审批鉴权限流统计；报表查询权限及资源限制。分别验证数据库差异；缺少对应环境时明确记录未验证范围。

## 交付顺序

1. 系统基础、组织权限、数据源和资产，以及数据库任务执行与运行记录。
2. 批处理工作流、持续增量同步、恢复及运维管理。
3. 数据服务与自助分析、报表和看板。
4. 跨模块数据权限、审计、部署与端到端验证。

上述均为首期目标，分阶段交付；具体技术选型、容量目标及详细接口在实施计划中结合部署环境确定。
